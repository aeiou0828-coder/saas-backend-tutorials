一、功能概述与配置流程

玩家满足设定的触发条件（充值、亏损、登录、在线时长等）并进入指定页面时，客户端弹出红包 / 宝箱 / 金蛋等弹窗，点击即可领取。弹窗会说明获奖原因，并提示玩家继续行动可获得更多奖励，从而引导持续充值、投注、浏览优惠。

能解决什么 用"不确定的惊喜奖励"刺激玩家充值 / 投注 / 浏览，提升活跃与留存
怎么发奖 为场景设"期望奖金"，系统按期望值随机发放；若配了等值奖励池，则按等值价值折算概率，随机发对应奖励
奖励类型 随机 / 固定奖金、幸运值、积分、活跃度、大 / 中 / 小盲盒免费次数、谢谢参与（未中奖）
客户端样式 7 种弹窗：开红包 / 满屏红包雨 / 开宝箱 / 砸金蛋 / 摇骰子 / 摇钱树 / 幸运抽签

配置四步流程

① 公共配置 设定哪些玩家 / 终端 / 条件可参与（门槛与防薅）
② 更多奖励设置 定义可开出的奖励类型、数值范围与等值价值（奖励池）
③ 新增触发场景 定义"什么条件触发、发多少、在哪个页面、用什么样式"
④ 打开意外惊喜开关 总开关开启后，已配置场景开始对玩家生效

过期口径：仅 1 次的奖励无过期时间；按周期的奖励在该周期结束后 + 1 天过期；不限次数的按 1 天为周期（如每笔充值次日 23:59:59 过期）。

说明 · 单笔充值场景每次满足都给，不限领取次数：单笔充值类场景按每一笔充值判断，玩家每次充值只要落在该场景区间内，都会获得对应奖励，不限制领取次数。例如场景配【单笔充值 100～500】，玩家这次充 200 得一份、下次充 300 再得一份。
说明 · 各场景相互独立，奖励可叠加，建议区间不重叠：每个场景独立判断、独立发奖，玩家一次行为会命中所有满足条件的场景并分别发奖。例如场景 1 配【单笔充值 100～200】、场景 2 配【单笔充值 100～500】，玩家充值 100 会同时命中两个场景，拿到 2 份意外惊喜。
因此同一类奖励配多个场景时，建议把区间配成连续、不重合的阶梯（如【100～200】【200～500】），避免区间重叠导致一次行为发出多份奖励、成本超预期。该建议适用于所有带【区间】的奖励条件（每笔 / 累计充值、充值次数、各周期亏损、在线时长等）。

奖励状态说明

一份奖励发出来后，会有这几种状态：还没领的是【待领取】；玩家领走了就是【已领取】；玩家把弹窗关掉、不要这份奖励就是【主动放弃】；一直没领、过了有效期就是【已过期】。在【奖励记录】里能看到每份奖励现在是哪种状态。

三、发奖逻辑：期望奖金与中奖概率

每个场景设一个"期望奖金（平均金额）"。系统算法保证全体玩家的实际平均奖金稳定落在期望值附近——单人有高有低，整体由算法兜底，按预算设好期望值即可控成本。发奖分两种方式：

未配【更多奖励】 直接在场景【奖金范围】内随机一个金额发放（纯现金），整体平均贴近期望奖金
已配【更多奖励】 每种奖励先按"等值价值"折算成金额，系统再按期望奖金反算各奖项中奖概率，随机命中后按折算关系发放对应数量的该奖励
举例： 设 1 幸运值 = 2 USDT，配置奖励 1-100 幸运值，相当于奖金 2-200 USDT；系统取其平均值与场景期望奖金对比，算出该奖项的中奖概率。玩家中奖时，按 1 幸运值 = 2 USDT 的关系发放对应数量的幸运值。

七、运营建议

运营者要完成的核心任务： 以最低现金成本，在玩家最可能行动的时机给一份惊喜奖励，引导其持续充值 / 投注 / 回访，同时防薅羊毛。
1. 什么场景用意外惊喜 做"行为即时正反馈"：玩家充值、登录、亏损到一定程度、VIP 升级时立刻给惊喜。亏损类（输光到、累计亏损）做流失挽回；充值 / 打码类拉存款与流水；在线时长激励停留。
2. 弹窗页面与样式怎么选 把"想引导的下一步"与弹窗页面对齐：拉充值 → 充值页 + 前往充值；盘活沉默玩家 → 大厅 / 从游戏返回首页。红包 / 红包雨快、转化高，适合新客大促；宝箱 / 金蛋 / 摇钱树仪式感强，适合中大额；抽签 / 骰子互动强，适合拉停留。
3. 用期望奖金控成本 期望奖金是人均奖励目标，系统算法保证实际平均稳定落在期望值附近。按"目标人数 × 期望奖金 ≤ 活动预算"设定即可控成本；奖金范围适当拉开增强惊喜感，平均仍由期望值兜底。配等值奖励池用幸运值 / 积分 / 盲盒次数替代部分现金，压低真实现金支出。
4. 成本与风控 公共配置设好"更多申领限制"（同 IP / 同姓名限领、首充、KYC / 绑卡）防薅羊毛；稽核倍数与稽核平台控制奖金提现，避免领了就走。亏损类触发阈值要谨慎，防刷亏损套利。
5. 怎么看效果 用【奖励记录】按时间 / 品牌 / 奖励类型导出，关注领取人数与领取率、人均奖励成本 vs 设定期望、领取后是否带来后续充值 / 投注，据此调整期望奖金、弹窗页面与样式组合。

八、常见问题 FAQ

Q：不配"更多奖励设置"可以吗？

A：可以。不配时直接按场景奖金范围随机发现金；配了之后才会按等值价值随机发幸运值 / 积分 / 盲盒次数等多样奖励。

Q："奖励价值"是干什么的？

A：把非现金奖励折算成等值金额，让系统能按场景期望奖金反算各奖项的中奖概率。例如 1 幸运值 = 2 USDT，配 1-100 幸运值相当于奖金 2-200 USDT。

Q：会不会有人开出很多、导致成本超支？

A：不会。系统有算法控制，全体玩家的实际平均奖金会稳定落在你设定的期望奖金附近，单人偶有高低，但整体成本由期望值兜底。

Q：玩家关掉弹窗后奖励还在吗？还能再领吗？

A：点"放弃"即取消奖励（后台记"主动放弃"）；若因任务未完成而未领，完成后奖励仍保留，可经首页悬浮图、或再次进入该场景页面重新弹出领取。

Q：充值成功后的弹窗什么时候弹？没领会自动补弹吗？

A：充值成功后弹窗在玩家充值成功后触发；若由此产生了待领取奖励（本次未领或被任务挡住），下次进入任意页面都能再次弹出提示领取。

Q：场景关闭后，待领取的奖励还能发吗？

A：场景关闭后玩家无法领取、也不再弹窗提示；如需发放，可在后台【奖励记录 / 待领取】中手动派发。
