一、登录/注册配置

 

（1）免注册配置

 

（返回顶部）

 

功能开启后使用新设备访问，会免注册自动生成临时账号（每个设备/指纹仅可生成一个临时账号，如果设备已经登录过正式账号，则无法再次生成临时账号），提升用户注册转化率。

临时账号仅限充值，无法领取奖励，无法参与正式游戏，且需完成充值后绑定对应账号的登录信息及设置提现密码，方可转为正式账号。

绑定账号的登录信息，与后台开启的登录支持方式一致。

充值成功后再强制要求绑定手机或邮箱后自动变成正式账号，避免账号和资产丢失。

“对游客展示首充将赠送的金额‘配置后对应币种生成的临时账号将展示对应“虚拟余额”，需要配合充值活动进行赠送，才能实现赠送；

 “升级正式账号绑定配置“可灵活配置临时账号升级为正式的验证项。

请注意：如果不使用原生或极速APP卸载后重新安装自动登录上次账号，请单独操作关闭(自动注册新的)

二、安全中心配置

强制安全绑定项(即提高账户安全):按照对应配置所需勾选，如勾选强制绑定，则注册成功后必须绑定完成对应验证项才可跳出，未勾选强制绑定则大厅验证页面右上角可点击跳出

注:如勾选绑定提现，必须同时勾选绑定提现密码且强制绑定

    勾选绑定手机、邮箱前必须先开启对应短信、邮箱配置

会员登录两步验证(提高安全)：

选择自愿两步验证：默认登录时验证用户已绑定的安全项中的手机/邮箱/谷歌验证 ，未绑定无需验证

选择强制两步验证：没绑定验证项的用户也可以登录，登录后若有提现密码就验证提现密码后强制要求绑定验证项，若无提现密码则直接强制要求绑定验证项中其中一项
强制关闭（不推荐）：会员登录时无需两步验证
注意：玩家登录两步验证后，10分钟内再登录时，是不会触发验证的。( 任何情境的两步验证皆适用 )

验证频率：选择适合的验证频率，如下

 

盟主账号强制安全绑定(提高安全)：

无 ( 不强制 )：不强制盟主帐号做安全绑定

三选一 ( 默认 )：强制安全绑定，可从验证手机短信、验证邮箱、验证谷歌验证器中，选择其中一种方式

多选：可以同时选择验证手机短信、验证邮箱、验证谷歌验证器三种方式，进行安全绑定

 

注册/绑定提现账号CPF验证(牌照相关建议使用)：

只校验规则，不通过第三方校验是否真实 ( 免费 )：即在设定提现账号时，只需要格式通过，不用校验真实性

使用第三方校验：绑定时，系统会自动侦测提现账号的信息，比对真实性，自动获取真实姓名与生日，且自动绑定至会员信息

可设定每日第三方验证次数上限，若超过次数则不自动验证
下方可查看每月验证的费用与明细

 

安全中心操作验证(即敏感重要资料先验证才能修改)：

勾选开启安全验证后，后台需要勾选下图任意一项验证项后才可以保存成功，对应大厅在安全中心新增/修改时，需要通过后台勾选的验证项中的任意1项才能新增/修改成功

注意1 : 若勾选的认证方式，用户没有绑定任何一项，则系统将会默认使用登录密码验证

注意2 : 勾选绑定手机、邮箱前必须先开启对应短信、邮箱配置。建议业主不要频繁变更短信和邮箱通道，容易造成缓存问题。

1、安全验证优先选项 验证手机短信，验证邮箱，验证谷歌验证码，验证密保等等

2、其次账号有资产，且没有绑定以上安全项的，且属于信任设备的，则无需验证，可以直接绑定其他安全项。
3、其次账号有资产，且没有绑定以上安全项的，且非信任设备的，则只能联系客服处理。
4、账号无资产，且没有绑定以上其他安全项的，且属于信任设备的，则无需验证，可以直接绑定其他安全项。
5、账号无资产，且没有绑定以上其他安全项的，且非信任设备的，则才是验证登录密码作为兜底。

无资产： 无余额 + 历史是否充值成功订单（充值成功、加款成功、接收成功、领取成功等额度变化的订单）

验证频率：选择适合的验证频率，如下

第一步验证项后提示文案改为：必选，勾选任意验证1项，若未绑定，则只能找人工客服
最后一步验证项后提示文案改为：选填，勾选任意验证项1项，不勾选则无需验证

资产安全设置：

首次设置提现安全项：勾选需验证登陆密码后，对应大厅在首次设置提现密码时，需要通过登录密码校验才能设置成功

提现资产保护：开启后每日首次提现或添加提现账号都需要两步验证，第一步验证提现密码

按照页面提示勾选操作，开启状态下必须勾选一项验证场景和一个安全验证项才能保存成功

如未绑定对应的安全项，则提示引导用户去绑定

注意：如果短信配置和邮箱配置存在上限或者失效，短信、邮箱配置自动关闭，会联动安全中心所有手机、邮箱相关的验证项关闭，关闭后在大厅没有二步验证，为避免此情况，建议一起勾选谷歌安全码做备用

 

 

设备信任开关&解锁验证（合规）：

安全配置中心的生物识别总开关,开启后客户端中安全中心展示该模块。 可用于免密码登录及自我禁止、提现、活跃度验证时调用

注册后引导开启生物识别弹窗：选中后玩家注册时引导开启玩家使用生物识别

登录默认优先生物识别/手势解锁：选中后玩家登录时默认优先生物识别/手势解锁

注意:若此开关在编辑状态下不可取消，请确认其他模块是否有开启生物识别功能。

三、短信配置

 

短信用途说明：

  1. 会员注册（若开启）
  2. 短信验证登录
  3. 忘记密码验证
  4. 找回密码验证
  5. 修改和绑定手机验证
  6. 自动召回-短信召回

 

 

短信字段说明：

  1. 短信通道ID：技术后台短信通道的唯一ID  
  2. 联系方式：该短信通道的联系方式
  3. 检测状态：该短信通道的检测状态，检测“成功”可启用/停用；检测“失败”，自动变为停用，不可改

  4. 运营商状态：该短信通道状态，运营商状态“无效”，自动变为停用

  5. 每日封顶：设置每日单个短信通道的发送数量，不设置不限制，每发送一条，今日剩余减少一条直到为0

 

短信排序说明:

  1. 根据排序依次向下轮询符合发送地区的短信通道
  2. 单个手机号5分钟内获取验证码超过两次，则触发轮询
  3. 如果超过5分钟，则会重新回归到该地区排序最前的短信通道
  4. 如果短信达到了每日封顶数量，则会踢出轮询
  5. 所有短信都达到上限后，暂停短信验证隔天解除。（如果达到上限，前台会显示短信服务已达上限，请联系客服）

 

添加短信平台步骤

1，点击新增

2，选择国家后，会显示支持这个国家的短信平台，根据联系方式可以联系第三方开通使用

API_KEY及API_SECRET
API_KEY及API_SECRET是API的账户及密码（字母或数字构成，共 8 位），用户唯一标识，可在客户端后台获取，请妥善保管。
Sender ID
Sender ID是显示在收信人手机上的发信人名称，常见格式为电话号码或者包括字母和数字的字符串。PaaSoo平台支持20个字符以内的Sender ID。
如果通过PaaSoo开放平台 API的from参数传Sender ID，请首先通过URL Encode方式进行编码转换（如需测试URL Encode，请使用http://www.url-encode-decode.com）。
请注意某些国家支持自定义Sender ID，也有部分国家需要和本地运营商注册专用Sender ID，所以PaaSoo平台不能保证from参数传送的字符串可以正确地以Sender ID形式显示在所有用户的手机上。
如需相关的帮助，请联系客户经理或者PaaSoo技术支持部门。

四、邮箱验证配置

 

 

邮箱用途说明:
  1. 会员注册(若开启)
  2. 验证邮箱登录
  3. 忘记密码验证
  4. 找回密码验证
  5. 修改和绑定邮箱验证
  6. 自动召回-邮箱召回

 

 

邮箱排序说明:
  1. 根据排序依次向下轮询
  2. 若5分钟内该邮箱被获取超过两次验证码，则触发轮询
  3. 如果超过5分钟，则会重新回归到排序最前的邮箱
  4. 如果邮箱达到了每日封顶数量，则会踢出轮询
  5. 所有邮箱都达到上限后，暂停邮箱验证隔天解除。（如果达到上限，前台会显示邮箱服务已达上限，请联系客服）

 

 

  1. 发件人：发件箱名称
  2. 每日封顶：设置每日单个短信通道的发送数量，不设置不限制，每发送一条，今日剩余减少一条直到为0
  3. 邮箱验证；开启后 会员在客户端绑定邮箱将可以使用验证。
  4. 支持同时配置多个邮箱
  5. 增加了邮箱验证发送排序优先级匹配和轮询

  6. 按排序优先级匹配，排序匹配规则：

    （1）若排序1连续被获取两次验证码，第三次触发调用排序2，依次轮询
    （2）当前邮箱发件服务达到每日上限后，不参与排序

    建议至少配置5个邮箱以上，邮箱使用的时间越久，风控的几率越大，风控的主要表现为邮件发送失败（企业每日上限10000，可能发送几百就无法发送，因为触发风控上限，所以出现批量失败的情况），大量失败即可把置顶向下移动或者关闭
    建议多准备一些企业或者个人邮箱，或者组合起来使用
    当失败的时候有备用可以切换，以免影响邮箱相关功能

五、会员基本信息

（1）设置需获取的会员基本信息，开启开关后会在客户端个人资料页面展示。

（2）新增【合规】相关资料：

1、真实姓名：开启后，客户端个人资料页面可输入真实姓名，已设置过的仅展示，校验规则同注册页

是否展示到注册页：勾选后在注册页面展示

提现时才检查绑定：勾选后在提现时必须先绑定真实姓名

允许会员修改真实姓名：勾选后可设置相关条件修改真实姓名

允许会员修改查看姓名：勾选后客户端验证提现密码即可查看已绑定的真实姓名

同姓名注册限制

真实姓名仅支持大写字母（推荐开启）

2、身份证号

是否展示到注册页：勾选后在注册页面展示

提现时才检查是否绑定：勾选后在提现时必须先绑定身份证号

允许同身份证号ID注册多个会员账号：仅对秘鲁、巴西币种生效

3、国籍/地区、出生地、当前居住地、永久居住地、雇主名称、工作性质、收入来源、这些开关默认关闭，开启后才展示后面配置内容

4、是否展示到注册页：勾选后在注册页同步展示，如注册页面填写成功，个人资料页面可展示

5、是否必填：勾选后如注册页也勾选，则注册页为必填，前面注册页未勾选则个人资料页面为必填

6、提现检查是否完善此项资料：勾选后如前面都未填写，将在提现页面再次弹窗提醒

7、KYC认证：按照步骤勾选，此项功能必须有【KYC配置】才能才能开启使用，可配置提醒文案

8、手持身份证自拍照：按照步骤勾选

9、规定时间内完善进行冷冻限制：所有会员都生效，配置好时间，到期后客户端会触发强制填写的弹窗，填写完成后可操作页面，未填写无法进行其他操作（即冷冻限制）

10、提现时提醒文案：按照提示配置

11、CPF自动获取生日(收费)：BRL币种下可以使用，开启后已配置CPF校验后但还未填写生日时，点击客户端个人资料的【获取】即可自动获取生日，CPF错误时则无法获取

（3）昵称和敏感词设置

1、加密展示：开启加密后昵称仅展示后4位

2、敏感词过滤：开启后可手动输入敏感词进行过滤，客户端不展示已设置的敏感词
