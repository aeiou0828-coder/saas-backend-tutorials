一、留存统计

（1）功能说明：主要分析新增会员的留存情况，于首充日之 第2 ~ 30日、第45日、第60日之后续留存人数；其中，二页面「精准算法」和「市场普遍算法」定义稍有差异，具体示例如下。

 

      举例而言，充值留存(精准算法)页中， 2025/6/19 首充者 1万人，于第 2 日(2025/6/20当日)，此 1万人中有 1988人有充值，充值留存率是 19.88% ( = 1988 / 10000 ) 。

 

      举另一例子，充值留存(市场普遍算法)页中， 2025/6/19 首充者有 1万人，于第 2 日之后(2025/6/20当日及以后)，也就是2025/6/20至今，这段期间中此 1万人中有 1988人有充值，充值留存率是 19.88% ( = 1988 / 10000 ) 。

    

（2）首充人数：该日期首次充值之人数，即首充者之数目（不论其注册日期为何，当一会员进行首充，该会员即成为那天的首充者）

（3）首充金额：即首充者的首次充值金额总和

（4）N日充值金额：恰第N日(精准算法)，或是第N日至今(市场普遍算法)，该日同批首充会员回头来充值金额之总和

（5）充值留存率：

  「精准算法」各日首充者于第N日当日，有充值者，其人数 ÷ 该日首充人数 x 100%

  「市场普遍算法」各日首充者于第N日(含)后 (即第N日至今)，有充值者，其人数 ÷ 该日首充人数 x 100%

（6）复充比例：各日首充者于首充当日充值两次或以上的人数 ÷ 该日首充人数 x 100%

（7）二充比例：各日首充者，自首充日至今，充值两次或以上之人数 ÷ 该日首充人数 x 100%

（8）分页与搜索：充值留存(精准算法)、充值留存(市场普遍算法)页签是以会员再回来充值的日期范围 (精准算法vs市场普遍算法定义如上) 作为留存计算方式，并可以分类多选代理帐号、代理ID，且区分俱乐部。

（9）设备端充值留存和投注留存：前者为充值留存再细分用户设备，后者是将留存的定义从充值变成投注。请注意，因为此次改动发版日为2025/08/27，因此数据仅会于该日后完整统计，该日之前的数据不是完整数据，也无法重跑或清除。

（10）投注留存和子游戏留存：前者为投注留存，后者乃投注留存细分子游戏，但相较于投注留存存，子游戏留存不是用首充者当基底，而是以每日投注者作为计算基准。请注意: 因子游戏留存发版日为2026/10/26，因此数据预计仅会于该日后完整统计。
