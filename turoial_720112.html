一、功能概述

信用借款为玩家提供【信用借款额度】，玩家先借款、后续还款，平台通过额度管理、审核、逾期管控来控制风险。入口在 优惠 → 信用借款。信用借款分 娱乐城 和 俱乐部 两种模式，按品牌组二选一，本教程先讲娱乐城、再讲俱乐部。

对比项 娱乐城模式 俱乐部模式
客户端入口 展示，玩家自助申请 不展示（纯后台 / 找客服）
放款方式 玩家申请 → 后台审核 → 到账 后台手动放款 / 调额度
额度来源 按 VIP/SVIP/累计充值/打码/亏损 多维自动算 后台逐人手动配
后台子页 9 个（含借款审核、借款会员列表等） 5 个
适用场景 规模化大众玩家自助借款 高净值 / 线下信任客户

配置维度（多币种 / 多品牌）

借款公共配置按站点形态分两种，均在【借款设置】弹窗内配置：

站点形态 配置方式
多币种站点 直接按币种配置借款详情。
多品牌站点 ① 品牌默认配置：全品牌默认套用的配置；② 品牌组：可 新增多个 ，每个品牌组选不同品牌、单独开关、单独设置借款配置详情， 不同品牌组可用不同模式 / 参数 。

二、娱乐城模式

2.1 借款设置（配置）

在 优惠 → 信用借款 页，点击右上方【借款设置】按钮打开配置弹窗，【借款模式】选择 娱乐城模式 。多品牌站点按品牌组配置、多币种站点按币种配置。按下表逐项填写：

序号 字段 填写说明
1 借款模式 选【娱乐城模式】。
2 选择币种 多币种站点选择适用币种。
3 借款是否需要人工审核 需人工审核 / 自动立即到账。玩家申请后是否需后台审核。
4 默认借款天数 单笔借款的可借天数，到期需还款。
5 还款金额 不限制（可分次任意还）/ 必须一次性还清。
6 是否允许二次借款 允许（随时可借）/ 不允许（先还清才能再借）。
7 周期内借款次数 每日 / 每周 / 每月 可借款次数上限（0 为不限制）。
8 借款期间优惠限制 4 选 1，详见下方说明。
9 借款期间是否可提现 禁止提现 / 可提现。
10 强制自动还款 3 选 1，详见下方说明。
11 逾期次数限制 设置 X 次，会员逾期累计达 X 次后禁用借款功能。
12 逾期前弹窗提示 逾期前 X 天 + 弹窗方式（每次进入首页 / 每次登录 / 每日一次 / 不弹窗）。
13 逾期后弹窗提示 弹窗方式（每次进入首页 / 每次登录 / 每日一次 / 不弹窗）。
14 可借款层级 勾选允许借款的 VIP 层级，用于圈定人群。
15 更多借款限制 4 项可独立勾选，详见下方说明。
16 按 VIP 等级获得额度 开关；按币种为各 VIP 等级（VIP0~VIP23）逐级配额度，可【应用到其他币种】批量复制。
17 按 SVIP 等级获得额度 开关；按币种为各 SVIP 等级逐级配额度。
18 按累计充值获得额度 开关 + 充值方式 + 奖励类型（固定金额 / 按比例），详见下方说明。
19 按累计打码获得额度 开关 + 有效打码平台（不限制 / 仅限 / 排除）+ 奖励类型。
20 按累计亏损获得额度 开关 + 有效打码平台 + 奖励类型；按累计亏损金额分档。
21 借款金额稽核倍数 借款后需完成的流水倍数（提现门槛）+ 稽核指定平台（不限制 / 仅限 / 排除）。
22 规则说明 自定义 / 系统自带。展示在客户端的借款规则文案。

借款期间优惠限制说明（4 选 1）

选项 含义
可领取优惠 借款期间一直可领取奖励（含逾期后）；领取后到余额，可用余额还款。
可领取优惠（逾期后不可领取） 借款期间可领，一旦逾期即停止领取。
禁止领取优惠（还款后可领取） 未还清不能领取，还清后才可领。
优惠自动作废 借款期间产生的奖励直接作废、不可领取。

强制自动还款说明（3 选 1）

选项 含义
开启但不追缴（逾期定时扣款） 逾期触发时自动还款一次，扣一次为止、不持续；可设扣款时间。
开启且追缴（逾期实时扣款） 逾期后实时扣款，持续直到还清。
关闭 不自动还款，由会员主动还或后台手动还。

额度获取说明（累计充值 / 打码 / 亏损 维度）

VIP / SVIP / 累计充值 / 累计打码 / 累计亏损 五个维度各自独立开关， 开启的维度额度累加求和 ＝ 该会员系统自动总额度 。额度 每日自动更新，且玩家访问借款页面时实时更新 。其中累计充值 / 打码 / 亏损 的奖励类型二选一：

奖励类型 说明
固定金额 按累计区间（≥X）配【可借款金额】，可多行阶梯，新增 / 删除。
按比例 按累计区间（≥X）配【可借款比例（%）+ 借款上限】，可多行阶梯。

更多借款限制说明（4 项，可独立勾选）

限制项
同登录设备号只能 N 个用户借款
同浏览器指纹只能 N 个用户借款
最近 X 天内充值次数 ≥ Y 次才能借款
最近 X 天内充值金额 ≥ Y 才能借款

2.2 借款审核与管理

开启人工审核后，后台在【借款审核】页对申请单进行通过 / 拒绝。点击【通过】弹窗可查看会员基本信息，并可修改【实际借款金额】（默认等于申请金额）。
操作 / 子页 说明
借款审核 通过（可改实际借款金额）/ 拒绝；支持批量通过 / 批量拒绝。
借款中 / 已逾期 行操作＝详情 / 强制还款（娱乐城系统自动额度，后台不手动放款，只能强制还款）；批量强制还款 / 批量取消追缴。
借款会员列表 按会员维度管理；行操作＝修改额度 / 禁用；顶部【新增】可手动给会员配信用额度（少量 / 批量添加）；批量支持修改 / 上调 / 下调 / 归零额度、强制还款、禁用 / 取消禁用。

记录 说明
借款中 / 已逾期 / 已还清 / 拒绝或取消 / 全部记录 按订单维度展示借款单：单号 / 借款金额 / 已还 / 待还 / 状态 / 追缴状态 等，按状态分页查看。
额度调整记录 额度变动留痕：调整前 / 调整金额 / 调整后 / 额度类型 / 调整动作 / 操作人。
借还记录 每笔借 / 还流水：借还类型（借款 / 还款）、借还方式（后台手动借款 / 系统自动借款 / 申请借款 / 主动还款 / 到期系统自动扣款 / 强制还款 / 追缴扣款）。

2.4 玩家端效果

娱乐城模式在客户端展示借款入口（优惠 → 信用借款）。顶部显示账户余额与利息宝；主卡片左侧为【可解额度 / 总额度】与【信用借款】按钮，右侧为【待还金额】与【我要还款】按钮。 借款流程： 玩家点【信用借款】→ 输入借款金额（不超过可解额度）→ 提交；需人工审核则进入【审核中】，自动立即到账则直接发放至余额。 还款流程： 点【我要还款】→ 选借款单 / 输入还款金额 → 用余额或利息宝还款（每笔需全额还，无利息）。

客户端 Tab 玩家看到什么
借款和还款规则 借款规则、还款规则、条款细则（即后台【规则说明】配置的展示），帮玩家了解额度、审核、限制、逾期后果。
额度来源 展示总额度由哪些维度构成（VIP 等级 / 累计充值 / 有效投注 / 后台固定额度 等）、各维度 + 多少额度及更新时间。
借款记录 玩家自己的借款单及状态（审核中 / 使用中 / 已逾期 / 已拒绝 / 已取消 / 已还清 / 逾期还清），可按时间 / 状态筛选。
还款记录 玩家的还款流水及方式（主动还款 / 到期扣款 / 强制还款 / 追缴扣款）。

三、俱乐部模式

3.1 借款设置（配置）

同样在【借款设置】弹窗，【借款模式】选择 俱乐部模式 。俱乐部为纯后台手动放款，额度由后台逐人配置，因此 不依赖娱乐城的"按 VIP/累计充值/打码/亏损 自动算额度" ；天数、还款金额、借款期间优惠限制、逾期次数、弹窗提示、稽核倍数等基础项与娱乐城一致（见 2.1）。俱乐部特有一项开关：

配置项 说明
是否允许会员在额度范围内任意使用 是 ＝无需找客服，玩家玩游戏时在额度内自动借款； 否 ＝只能找客服上分（纯后台手动放款，客户端无入口）。

3.2 后台管理操作

俱乐部在【借款中 / 未借款】子页对会员行操作，全部由后台手动完成。已有欠款会员显示：上调额度 / 下调额度 / 手动加款 / 手动扣款 / 备注；未借款会员显示：上调额度 / 手动加款 / 手动扣款 / 备注。每笔资金操作均需验证登录密码。
操作 说明
上调 / 下调额度 上调＝抬高总额度上限并自动把可借部分全部借出到玩家可用余额；下调＝压低总额度上限，必要时直接从玩家可用余额扣回欠款作为还款（无独立还款按钮，还款由下调自动触发）。
手动加款 / 手动扣款 调用财务模块弹窗，给会员加余额 / 扣余额（属财务功能）。
备注 登记会员前台 / 后台备注。
下调金额最大值是怎么算的？
看两块加起来：① 没借出去的额度（总额度还没用完的部分，可以直接砍）+ ② 玩家钱包里能还回来的钱（取玩家当前可用余额和欠款两者中较小的那个——能还多少看玩家钱包够不够还、最多也只能还掉已借的部分）。两者之和就是这次下调能填的最大值。
什么时候触发还款？下调金额超过【没借出去的额度】时，超出的部分系统直接从玩家可用余额扣回作为还款；不超过则只是降额度上限，玩家钱包不动。
例：玩家总额度 5000、当前借款 2000、可用余额 1500。没借出去的部分是 3000；玩家钱包能还回来的部分，可用余额 1500 比欠款 2000 少，所以取 1500；两块加起来，本次最多下调 4500。若下调 4500，超出没借出去的 3000 的部分（1500）走还款扣玩家余额；若下调 2000（没超过 3000），玩家余额不动，只压总额度上限。

底部【批量操作】：借款中页支持 批量上调 / 下调总额度、批量开启 / 关闭追缴；未借款页支持 批量上调 / 下调总额度。批量操作需选择会员并验证登录密码。批量上调＝逐人按各自总额度自动借出；批量下调＝逐人按各自下调金额最大值校验，超限拦截整批。

四、站点后台账号可设置借款限额

站点后台支持给各运营账号配置信用借款上调/下调操作的限额，按【账号 × 币种】维度独立管控。

4.1 配置位置

站点后台 → 账号管理 → 新增账号 / 编辑账号 → 限额管理 → 批量设置限额，找到【信用借款上调限额】和【信用借款下调限额】两项，按币种 tab（CNY / USDT 等）独立配置。

4.2 字段说明

序 字段 说明
1 额度限制 不限制 / 每日 / 每周 / 每月。选不限制时右侧三个金额输入框置灰；选每日/每周/每月时输入框激活
2 每日/每周/每月限额 该周期内可累计操作的金额上限，超出当周期不可继续操作。
3 总额度 从配置生效起累计上限；可空，空=不设总上限
4 单笔最大额度 单次操作金额上限，超出直接拦截。

4.3 校验逻辑与重置

运营账号在【信用借款】发起单次/批量上调或下调时，按以下顺序校验：① 单笔最大额度 → ② 周期累计限额 → ③ 总额度 → ④ 币种匹配。任一项超限即拦截，提示具体超限项。批量按合计金额参与累计，任一会员超限整批拦截。

上调/下调独立计数：按【运营账号 × 币种 × 限制项（上调/下调）】维度独立累计，上调累计不影响下调额度，反之亦然。

币种匹配规则：校验时按操作会员的币种取对应币种的限额配置；该币种未配限额则按【不限制】处理。混币种批量操作按各自币种限额分别校验。

周期重置：每日 00:00 / 每周一 00:00 / 每月 1 日 00:00（站点统一时区）；总额度永不重置，达上限后需管理员手动调整配置。

修改影响：调整限额配置后，已发生的操作不回滚仍计入累计；新限额对此后操作生效；调低后当前周期已超 → 当周期不可继续操作（直到下个周期重置）。

五、运营建议

维度 运营建议
额度策略 娱乐城额度建议"基础 + 浮动"组合——用 VIP / SVIP 等级给基础额度（身份激励），用累计充值 / 打码 / 亏损 给浮动额度（贡献激励）。高价值维度用【按比例 + 借款上限】随贡献增长又封顶控险；低活跃维度用小额【固定金额】托底。配合【可借款层级】把额度只开放给目标人群。额度每日自动更新、访问页面实时刷新。
转化技巧 追求转化率时【借款是否人工审核】选【自动立即到账】，减少等待、提高成功率；风险敏感站点保留【需人工审核】把关大额。借款期间【可领取优惠】让借款玩家继续领奖、领奖到余额又能还款，形成"借款—活跃—还款"循环。
风控与成本 用【借款金额稽核倍数】设提现流水门槛防套现；用【逾期次数限制 + 强制自动还款（追缴）】控坏账；用【更多借款限制】（同设备 / 指纹 / 近期充值门槛）防多账号薅借款。保守站点可叠加【禁止领取优惠 + 借款期间禁止提现】。
逾期管理 配置逾期前 / 逾期后弹窗提示提高主动还款率；按坏账容忍度选强制还款力度——"开启不追缴"较轻、"开启且追缴"较重。定期在借款会员列表按"已逾期 / 累计逾期次数"排查高风险会员。
效果怎么看 ① 规模：借款渗透率、人均借款额、借款拉动的流水增量；② 风险：逾期率、坏账率、追缴回收率；③ 数据源：借还记录看资金流转，借款会员列表看渗透与风险，全部记录看整体借 / 还规模。

六、常见问题 FAQ

Q：俱乐部模式和娱乐城模式最大的区别？

A：俱乐部纯后台手动放款、客户端无入口；娱乐城客户端有入口、玩家自助申请、额度系统自动算。子页和操作也不同（娱乐城多审核态、订单维度，9 子页；俱乐部会员维度，5 子页）。

Q：会员的借款额度是怎么算出来的？

A：娱乐城模式下，开启的各维度（VIP/SVIP/累计充值/打码/亏损）额度相加＝总额度，每日自动更新、玩家访问借款页面时实时更新；俱乐部模式由后台逐人手动配置。

Q：借款期间玩家还能领优惠、提现吗？

A：取决于【借款期间优惠限制】（4 选 1）与【借款期间是否可提现】配置，可按风控需要设为可领 / 逾期后不可领 / 禁止领 / 自动作废，以及禁止 / 允许提现。

Q：玩家逾期不还怎么办？

A：可开启强制自动还款（不追缴＝逾期扣一次 / 追缴＝实时扣到还清）；逾期累计达【逾期次数限制】会自动禁用借款功能；后台也可手动强制还款。

Q：为什么客户端看不到借款入口？

A：借款入口仅娱乐城模式展示。俱乐部模式客户端无入口，借款由后台或客服操作。

Q：审核通过时可以改借款金额吗？

A：可以。娱乐城借款审核【通过】弹窗的【实际借款金额】可编辑，默认等于玩家申请金额，后台可调整实际放款额。
