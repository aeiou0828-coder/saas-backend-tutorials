一、功能概述

加倍奖励是一个 奖励模板 ：配置一次，可被其他活动（如任务中心）重复调用。玩家在活动中拿到奖励后，系统弹窗提示「还可再领一份加倍奖励」，引导玩家充值；玩家充值并满足条件后即可领取（奖金设有上限、不会无限增大）。一句话： 它是一把"用奖励翻倍来撬动充值"的运营杠杆 。

维度 说明
奖金算法 加倍奖金 ＝ 赠送金额 × 倍数，或 充值金额 × 倍数（二选一）
领取前提 玩家必须先完成一次充值才能领取
能解决什么 促充值转化、提升客单价（ARPU）、挽回流失、新客首充激励、为主活动加码
目前接入 后台手动派发、任务中心（其他活动后续接入）

二、新增加倍奖励

在「加倍奖励列表」页，点击右上方的「新增加倍奖励」按钮，弹出配置弹窗（如下图）。按下方字段说明表逐项填写，带 * 为必填项，填写完成后点击「确认」保存。

字段说明表

序号 字段 必填 填写说明
1 加倍奖励名称 是 便于识别的名称，例如「任务中心－充值加倍」
2 加倍奖励规则 是 奖金算法二选一，详见下方规则说明
3 充值方式 是 勾选生效的充值渠道（银联、银行、虚拟币、PayPal 等），默认全选；玩家须用勾选渠道充值才触发
4 加倍方式 是 倍数规则三选一，详见下方加倍方式说明
5 领取条件／加倍奖金上限 是 随第 2 项联动出现，详见下方规则说明
6 加倍奖金稽核平台 否 流水统计范围：不限制／仅算勾选平台／排除勾选平台
7 充值前是否展示稽核倍数 否 开＝玩家充值前不展示流水提示；关＝展示
8 派发方式 是 发放方式三选一，详见下方派发方式说明
9 有效期 是 奖励有效天数，范围 1～31 天
10 弹窗样式 是 玩家端弹窗外观：红包／宝箱／福袋，可点预览
11 后台备注 否 内部说明，选填

规则说明

规则 奖金算法 联动出现的设置
赠送金额的倍数 主活动赠送金额 × 倍数 领取条件（单笔充值满 X 元才可领，填 0 ＝ 任意金额）
充值金额的倍数 本次充值金额 × 倍数 加倍奖金上限（最多发放金额，填 0 ＝ 不封顶）

三、管理已配置的加倍奖励

操作 说明
修改 与新增同一张填写表，可调整内容；修改仅对之后新生成的奖励生效，已产生的保持原配置不变

四、查看玩家领取情况

在「领取记录」中，按玩家所处状态分页签查看，如下图：
状态 含义
未完成 玩家已获得奖励，但尚未充值
已完成 玩家已充值，但尚未点击领取
已领取 玩家已充值并成功领取
已过期 超时作废的奖励
被拒绝 后台手动拒绝或取消的奖励
全部记录 汇总全部状态，可按状态筛选

列表支持按时间、金额排序，并可点「导出报表」导出。

五、玩家端展示效果

玩家在活动中领取奖励时弹出领取窗；若该奖励配置了加倍，则弹出加倍窗：玩家可选「直接领取」（放弃加倍、仅拿原奖励），或点「超级加倍」去翻倍。点「超级加倍」后进入去充值流程，引导玩家完成充值；玩家充值并满足条件后，加倍奖金到账。

玩家端弹窗样式（红包 / 宝箱 / 福袋）与"直接领取 / 超级加倍"按钮，由配置时的「弹窗样式」决定。

六、运营建议

1. 什么场景用加倍奖励

运营场景 怎么用
节日／大促冲充值 挂在主活动上加码，用较高倍数 ＋ 短有效期制造紧迫感
新客首充转化 低门槛（领取条件填 0 或小额）＋ 固定倍数，降低决策负担
流失玩家召回 对回流玩家发较高加倍，配合弹窗钩子刺激回归充值
拉高客单价（大 R） 用「阶梯加倍」，充得越多倍数越高，引导大额充值

2. 三种加倍方式怎么选

方式 运营效果 建议场景
固定倍数 预期明确、成本最可控，玩家一眼看懂 新客转化、稳健促充值
随机倍数 制造惊喜与博彩心理、刺激性强；用"期望倍数"控大盘成本 活跃老玩家、节日造势
阶梯加倍 用倍数阶梯诱导更大额充值，拉高客单价 大 R 维护、冲业绩

3. 参数配置技巧（提转化）

参数 技巧
有效期 想快速冲量就设短（1～3 天）制造紧迫感；想覆盖更广人群可设长一些
领取条件／门槛 新客拉新填 0 降低门槛；控成本时设最低充值额过滤薅羊毛
弹窗样式 按活动主题选红包／宝箱／福袋，贴合氛围能提升点击与领取
充值前是否展示稽核倍数 关闭可弱化"流水门槛"的劝退感、提升点击转化；但要权衡玩家提现体验与口碑
充值方式 只勾选优质／低成本渠道，既引导玩家用好渠道，也便于成本核算

4. 成本与风控

风控点 说明
稽核倍数 设合理流水要求，防止"领了就提"套利；新客可适当低、老玩家可适当高
加倍奖金上限（充值倍数模式） 务必设上限封顶，防止大额充值爆奖、成本失控
随机倍数 靠"期望（平均）倍数"控大盘成本，上线后对照实际平均值监控

5. 怎么看效果

在「领取记录」按状态读数，快速判断活动健康度：

看什么 说明 / 动作
未完成占比高 钩子有吸引力但充值转化不足 → 可降门槛、缩短有效期、加大倍数
已领取 / 已完成 成功转化的量，结合充值金额评估 ROI
已过期占比高 玩家无感或门槛偏高 → 调整倍数、样式或人群
导出报表 结合充值单号、金额做 ARPU／转化率分析

七、常见问题 FAQ

Q：玩家充值了，为什么没领到加倍奖励？

A：玩家须点击弹窗内的充值按钮去充值才会计入；从其他入口充值可能不计。且第 1 笔充值需满足条件、产生奖金不低于 0.01，否则奖励作废。

Q：为什么某个加倍奖励删不掉？

A：该奖励正被某活动引用，删除前需先在对应活动中取消引用。

Q：修改加倍奖励，会影响已经产生的奖励吗？

A：不会。修改只对之后新生成的奖励生效，历史已产生的奖励仍保持原配置不变。
