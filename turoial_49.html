一、功能概述

VIP 是会员分层激励体系。按充值/打码量级把会员划分等级，配套日/周/月工资、晋级奖金、生日礼金、提现特权等差异化奖励。运营通过差异化激励留住高净值玩家。

维度 说明
入口 优惠 → VIP奖励（奖励层）；会员 → VIP等级（特权层 - 提现额度/次数/免手续费）
配置层级 VIP 列表按币种独立配置；多品牌共用一套（不分品牌）
最大等级 最多 100 级 + 默认 VIP0 = 共 101 级
奖励种类 晋级奖金（一次性）/ 日工资 / 周工资 / 月工资 / 生日礼金（5 类，独立配置）
奖励到账 先入【待领取】，玩家点领取走小额直领 / 大额审核；过期按公共配置自动到账或作废

二、配置 VIP 等级（按币种）

在【优惠 → VIP奖励】顶部下拉切换币种，每个币种独立配置一套等级表。如下图：

2.1 顶部按钮

序 按钮 说明
1 币种下拉 切换查看不同币种的 VIP 配置
2 应用到所有币种 把当前币种整套配置一键复制到勾选的其他币种（弹窗多选）
3 VIP开关 按币种控制（当前币种下生效）。关闭后：①该币种的 VIP 模块在客户端不展示；②该币种玩家的待领取 VIP 奖励也不能领取（领取入口同步关闭）。多币种站点需逐币种切换开关
4 VIP公共设置 所有币种/品牌通用的全局配置（保级/领取时间/派发方式/图标/常见问题等）
5 详情 查看最近 30 次修改历史 + 当前配置详情；不受权限控制
6 当前版本下拉 查看历史版本配置，只读不可回滚
7 + 新增等级 列表底部新增空行，可连续点击添加多行后依次填写、点【确认】提交
8 导入修正 按会员维度批量调 VIP 等级（详见 4.2）
9 批量修改 列表所有行变为可编辑，可逐行改也可下载 Excel 整体改后导入（详见 4.1）

2.2 VIP 等级字段

字段 说明
VIP 等级 VIP0 ~ VIP100；VIP0 为系统默认等级
当前人数 该等级当前会员数（点击可查看会员列表）
预览图 该等级 VIP 图标（按公共设置选的样式合成或自定义上传）
晋级需再充值 相对当前等级再充多少升级，与历史累计无关；填 0 = 不限制
晋级需再打码 同上，按再打多少升级；与充值是【且】关系，两项都达成才升级。两项都填 0 = 玩家直接达到最高等级
晋级奖金 升级时一次性发放的金额；0 = 无该奖励
上月充值 / 上月打码 保级条件（公共设置开启保级才生效）。上月达不到 → 下月用户登录时降级。0 = 不限制（不会因此降级）
月工资段 当月充值 + 当月打码 = 达标条件；月工资金额 = 单周期可领；月累计封顶 = 单月领取上限。填 0 = 无门槛领工资
周工资段 当周充值 + 当周打码 + 周工资 + 周累计封顶（同上）
日工资段 当日充值 + 当日打码 + 日工资 + 日累计封顶（同上）
生日礼金 生日当天 00:00 后可领的金额；0 = 无
操作 修改（行内编辑→取消/确认）
注意：各类奖励（晋级奖金、日/周/月工资、生日礼金）金额所有等级都填 0 → 客户端会隐藏该奖励板块。运营若想精简客户端展示，把不要的奖励类全填 0 即可。

三、VIP 公共设置

点【VIP公共设置】打开弹窗，所有币种与品牌共用这套设置：

3.1 全局开关

字段 说明
VIP升级时弹窗提醒 玩家升级时是否在客户端弹窗提示
保级开关 开启 = 不满足上月保级条件自动降级；关闭 = 永不降级
晋级奖励限制 ① 只可领当前等级对应的晋级奖励（默认）；② 可领取降级前等级已产生的晋级奖励（避免降级丢奖客诉）

3.2 五段奖励独立配置

每日工资 / 每周工资 / 每月工资 / 生日礼金 / 晋级奖金 五段，每段都有以下三项配置：

配置项 选项与说明
领取时间 次日 / 实时领取（影响留存） / 每日（每周/每月） / 下周（下月）。实时领取（影响留存）= 给运营的提示，建议次日领，实际运营中实时让用户当天领完就跑会拉低留存数据
晋级时是否重复领取 可重复领取（含跨级部分）= 跨过的中间等级奖励都补发，玩家可领多份；只能领最高一档= 只领最终等级，跨过的不补差但触发补差值（按当前等级金额-已发金额生成新奖励）
奖励领取过期天数 0 = 周期结束直接过期；> 0 = 周期结束 + X 天过期

3.3 派发方式（日/周/月/生日 通用）

派发方式 说明
玩家自领-过期自动到账 奖励先入待领取，玩家不点也不丢，过期系统自动发到余额（仍走稽核）
玩家自领-过期作废 过期未领则丢失，玩家需及时领取

3.4 其它设置（沿用站点通用）

领取终端、更多申领限制、禁止参与层级（黑名单）、稽核倍数、奖金稽核指定平台、规则说明（自定义/系统自带）。详见站点通用公共配置。

3.5 客户端展示设置

字段 说明
VIP常见问题 开关。开启后客户端 VIP 页底部展示常见问题板块；同时需在【运营→客服管理→常见问题】配置【问题类型=VIP】+ 状态【已发布】才会展示
VIP展示方式 列表展示 / 卡片展示，决定客户端 VIP 页的展示形态
图标样式 默认图标可按 VIP 颜色、等级样式自由组合配置（卡片展示模式还可叠加 VIP 背景），卡片样式额外提供 1-5 套预设；选自定义上传整图（≤1MB，240×240，最多 100 张）

3.6 领取时间与过期规则详解

每日 / 每周 / 每月 俸禄各自可单独配置领取时间与过期天数，组合方式如下：

领取方式 时间设置 领取规则
次日 单时间点（如 10:00:00） 今日产生的奖励，次日设定时间点以后可领取
实时领取 单时间点（如 10:00:00） 今日产生的奖励，今日设定时间点以后即可领取
每日 时间区间（如 10:00:00-15:00:00） 今日产生的奖励，仅每日设定时间区间内可领取
下周 星期 + 时间点（如 周二 10:00:00） 今日产生的奖励，下周指定星期的时间点以后可领取
每周 星期 + 时间区间（如 每周二 10:00:00-15:00:00） 今日产生的奖励，仅每周指定星期的时间区间内可领取
下月 日期 + 时间点（如 下月 2 日 10:00:00） 今日产生的奖励，下月指定日期的时间点以后可领取
每月 日期 + 时间区间（如 每月 2 日 10:00:00-15:00:00） 今日产生的奖励，仅每月指定日期的时间区间内可领取

过期规则总结

过期时间 = 周期结束时间 + 过期天数。

  • 过期天数 = 0：周期结束直接过期
  • 过期天数 = X 天：周期结束后第 X 天的 23:59:59 过期
  • 日俸禄周期 = 每日；周俸禄周期 = 每周（周日结束）；月俸禄周期 = 每月（月底结束）
  • 过期后按【派发方式】处理：自动派发到账 / 直接作废

示例 1：次日领取 + 过期 1 天

配置：领取方式=次日，选择时间=10:00:00，过期天数=1 天

奖励类型 规则
每日俸禄 17 号产生 → 18 号 10:00:00 后可领 → 18 号 23:59:59 过期
每周俸禄 本周（12-19 号）任意一天产生 → 次日 10:00:00 后可领 → 周期结束（周日 23:59:59）+ 1 天 = 下周一（20 号）23:59:59 过期
每月俸禄 11 月任意一天产生 → 次日 10:00:00 后可领 → 周期结束（11 月 30 日 23:59:59）+ 1 天 = 12 月 1 日 23:59:59 过期

示例 2：每周领取 + 过期 1 天

配置：领取方式=每周，选择时间=每周二 10:00:00-15:00:00，过期天数=1 天

每周俸禄：本周（12-19 号）任意一天产生 → 仅每周二 10:00:00-15:00:00 可领取 → 周期结束（周日 23:59:59）+ 1 天 = 下周一（20 号）23:59:59 过期。如本周内的可领时间窗（周二 10-15 时）已过且玩家未领，则只能等下周二再领，但要在过期前。

示例 3：每月领取 + 过期 7 天

配置：领取方式=每月，选择时间=每月 2 日 10:00:00-15:00:00，过期天数=7 天

每月俸禄：11 月任意一天产生 → 仅每月 2 日 10:00:00-15:00:00 可领取 → 周期结束（11 月 30 日 23:59:59）+ 7 天 = 12 月 7 日 23:59:59 过期。过期后按派发方式自动到账或作废。

四、批量操作与会员等级管理

4.1 批量修改 VIP 等级表配置

点【批量修改】，列表所有行变成可编辑输入框，顶部按钮变为【下载当前配置】【导入修改】【取消】【确认】。两种用法：

用法 操作步骤
列表手动修改 逐行修改字段 → 点【确认】保存提交
用 Excel 批量修改 点【下载当前配置】拿模板 → 在 Excel 改完 → 点【导入修改】预填到列表 → 检查无误后点【确认】才真正提交
说明：导入只是前端预填，不会自动提交。无论行内改还是 Excel 改，最终都要点【确认】才生效。

4.2 导入修正 - 批量调会员 VIP 等级

点顶部【导入修正】，弹窗按提示上传 Excel 即可批量调整指定会员的 VIP 等级。

安全验证：【导入修正】等需要身份校验的操作，是否要输入登录密码或 Google 验证码，统一由【系统管理 → 账号权限 → 安全设置 → 优惠审核验证】控制（仅持有者可见）；两项都设为无需验证时，提交后直接通过。
字段 说明
导入方式 严格校验（数据格式全部正确才上传）/ 自动跳过错误（不推荐）
数据上传 点击上传 Excel，每文档≤100 万条，文件≤50M
验证密码 需输入登录密码确认操作
模板下载 下载标准 Excel 模板，按字段顺序填写
导入修正后的关键约束（防薅羊毛）：
1、修改后会员的晋级累计从 0 开始重新算
2、修改后等级对应的晋级奖励不发
3、周期性日/周/月工资等下个周期才能领
4、会员列表批量新增导入会员遵循同样规则

4.3 详情 / 历史版本

入口 用途
详情 查看最近 30 次修改历史 + 当前配置详情；不受权限控制（任何运营都能查）
当前版本下拉 切换查看历史版本配置；只读不可回滚，如需恢复旧配置需手动改回

六、运营建议

VIP 不只是奖励发放工具，更是会员分层激励与情感连接体系。下表从玩家心理与运营节奏视角给出建议：

维度 建议
新人引导 前 2-3 级晋级条件设低，让新玩家快速升级，强化"已是 VIP"身份认同
充值促进 用【晋级奖金】+【晋级进度条】做"再充 X 元就升级"的钩子，撬动二次充值
展示方式 等级 ≤ 10 选卡片展示，权益对比刺激升级；等级 > 10 选列表展示
奖励包成本 各等级总奖励占该等级充值额的 5-15%，超出 20% 需审视
奖励组合 五类奖励选 2-3 类即可，集中预算撬动重点指标，不要的填 0 隐藏
大客留存 高 VIP 给身份感（专属图标 / 生日礼金大额），不只靠金钱；VIP 充值贡献率重点监控
仪式感设计 生日礼金做差异化（按等级金额拉开），晋级开启升级弹窗提醒，强化情感连接
流失预警 保级条件让 80% 玩家能保住；对临界保级玩家定向推活动，避免大面积降级流失
晋级奖励限制 保级开启时建议配【可领降级前已产生】，避免降级丢奖客诉
跨级处理 新站点配【可重复领取】激励充值；成熟站点配【只能领最高一档】控成本
活动配合 VIP 体系长期不变，活动短期叠加；月初配合签到/充值送，月末做晋级冲刺活动
特别说明（运营请仔细阅读）
  1. VIP 默认从 VIP0 开始，新注册会员默认 VIP0；VIP0 数值不可修改，固定为 0
  2. 日/周/月俸禄奖励：会员充值或打码后，每隔 10 分钟统计更新，奖励可在【领取与审核】页面查看
  3. VIP 晋级再充值/打码配置的是升级到下个等级的增量值，每一级到下一级都有各自的累计要求，达标就升级；升级后超出的部分不会清空，会接着算进下一级的累计里。举例：VIP1→VIP2 需要累计充值 100，VIP2→VIP3 需要累计充值 500。玩家从 VIP0 开始充值 400：先用 100 升到 VIP1，剩下 300 接着算进 VIP2→VIP3 的累计（此时 300/500）；玩家再充值 200，累计达到 500，升到 VIP3。
  4. VIP 配置修改可能导致玩家立即升级。例：当前玩家 VIP2，原配置 VIP2→VIP3 需打码 1000，改成 500 后玩家可能立即升 VIP3。请谨慎修改运行中的 VIP 配置
  5. 手动调整 VIP 等级后，晋级到下个等级的充值/打码累计从 0 重新开始计算
  6. VIP 降级时：之前等级未领取的日/周/月俸禄都不可领取；晋级奖金一个等级仅可领 1 次（之前领过不再领，未领过的根据【晋级奖励限制】决定能否领）
  7. 日/周/月俸禄充值/打码条件均配置为 0 时，玩家必须在周期内登录并进入 VIP 页面才会产生奖励（无条件奖励懒加载）

七、常见问题 FAQ

Q：奖励是定时统计还是实时的？

A：有条件奖励（充值/打码>0）每 10 分钟统计一次，仅扫这 10 分钟内有充值或有打码变动的用户（不全量）；无条件奖励（条件全 0）懒加载，玩家访问 VIP 页时触发即时生成。

Q：多币种 VIP 怎么配置最快？

A：先在主币种配好整套 VIP 表，然后点【应用到所有币种】快捷复制到其他币种。但要按各币种汇率/购买力再调整奖励金额，不能简单等值复制。

Q：列表展示和卡片展示怎么选？

A：等级数多（10+）选列表展示更紧凑；等级数少（≤10）选卡片展示，权益对比区引导玩家升级。两种展示对应的图标样式可分别配置。

Q：客户端 VIP 页的常见问题怎么不显示？

A：三段满足才会展示：① 公共设置开启【VIP常见问题】开关；② 在【运营→客服管理→常见问题】配置【问题类型=VIP】；③ 该问题状态是【已发布】。

Q：批量新增会员或批量修改会员 VIP 等级后，会员说各种奖励都不能领取？

A：这是设计如此。批量新增导入会员或导入修正调级后：①晋级累计从 0 重新算；②当级晋级奖金不发；③周期性日/周/月俸禄等下个周期才能领；④生日礼金按新规则需后台审核（针对今年内）。这是为了防多账号薅羊毛与运营误操作。批量操作前请告知玩家或单独配奖励派发。
