一、功能概述

折扣券是一种【充值打折券】。会员充值时勾选可用的折扣券，即可按折扣少付：例如【充值 100 减 9】，会员实际支付 91 元，账户仍到账 100 元——其中 91 元为本金到账、9 元为优惠到账。

能解决什么 用【充值立减】刺激充值与提升客单价；可注册自动发放拉新、也可手动发放给指定会员。
奖励方式 固定金额（满 X 减 Y）/ 比例金额（满 X 按比例减、可设上限）。
到账与提现 实付部分为本金、折扣差额为优惠到账；优惠按【稽核倍数】打满有效投注后方可提现，并受【奖金提现方式】限制。
展示前提 折扣券总开关开启，且会员满足 会员层级 / VIP 等级 / 渠道或代理 / 使用条件，客户端才展示入口与可用券。

二、新增折扣券（配置步骤）

在【折扣券列表】页点击右上方【+ 新增折扣券】按钮，弹出配置弹窗，如下图。
序号 字段 必填 填写说明
1 选择币种 是 勾选该券适用币种，可全选。多品牌站点此处改为【品牌名称(ID)】，按品牌发券。
2 是否启用 — 开关；关闭则该券不生效。
3 使用有效天数 是 0～31 天，0 表示不过期。自会员获得时间起 + 天数的 23:59:59 过期。修改天数：未使用券过期时间会更新，已失效券不更新。券过期后，后台仍保留 60 天可查、客户端【已失效】内 60 天可见，超期清除。
4 充值方式 是 勾选的充值方式才能使用本券（如 PIX、数字币 app 等），可全选。
5 稽核方式 / 稽核倍数 是 只稽核奖金 / 稽核奖金+本金；倍数即需打满的有效投注倍数（如 1.00）。达标后优惠方可提现。
6 奖金稽核指定平台 — 不限制 / 仅限勾选平台 / 排除勾选平台（计入打码的游戏平台范围）。
7 奖金提现方式限制 — 不限制 / 仅限勾选方式（如只能用 USDT、NO 钱包提现）。
8 参与渠道或代理 是 开关；指定渠道 ID / 指定代理账号 / 排除渠道 ID / 排除代理账号，并选择对应项。
9 注册后立即自动发放 — 开关（推荐开启）。开启后所有会员注册即自动到账折扣券、不区分层级，后台有发放记录；实际使用时才读取参与层级、渠道、币种、品牌等通用条件，满足才在客户端展示。
10 奖励类型 + 奖励设置 是 见下【奖励设置说明】，可配多档（折扣券名称 + 新增/删除）。
11 前台备注 / 后台备注 — 前台备注在玩家端【详情】展示；后台备注仅内部可见。各 0～1000 字。

奖励设置说明

固定金额 填【充值金额≥、折扣金额】，系统显示【实际支付】。例：充值金额 100、折扣金额 9 → 实际支付 91。会员充满 100 即少付 9。
比例金额 填【充值金额范围、折扣比例、折扣上限】，系统显示【实际支付】。例：充值 100～10000 减 20%。〔优惠=充值×比例、最高不超过折扣上限——具体口径待与开发确认〕

公共配置（通用，所有优惠模块一致）

点顶部【公共配置】设置领取与使用门槛：领取终端、更多使用限制、指定会员层级、指定 VIP、过期提醒、折扣券样式（客户端展示样式 1～6）。层级或 VIP 不符的会员，客户端不展示折扣券入口。

三、管理操作

折扣券总开关 顶部开关，关闭后客户端不展示折扣券入口。
修改 修改券配置；对【未使用】的券实时生效（有效天数、配置在使用时实时读取），已使用/已过期券数据已固化、不受影响。
删除 删除后后台不再保留、无法查看；会员客户端在【已失效】里最长保留 60 天仍可查看，超 60 天清除。
发放 手动发放给指定会员。单次发放：输入会员账号/会员 ID，多个用逗号拼接（≤200）；批量发放：数据上传（每文档≤100 万、≤50M，可下载模板）。新增的折扣券需发放后会员才能看见使用——可开启注册后立即自动发放、或在此手动发放给指定会员。

四、查看记录

列表区共 5 个页签：【折扣券列表】为券配置列表（每行一个券，含币种、有效天数、充值金额范围、奖励类型、折扣金额/比例、稽核倍数、未使用/已使用/已过期统计（点击统计数字可跳转对应记录页）、操作）；【未使用 / 已使用 / 已过期 / 全部记录】为会员领取记录，可按时间、品牌、币种、会员、券、奖励来源等搜索；【全部记录】额外含 状态、充值金额、充值订单、使用时间、赠送金额，并可导出报表。

五、玩家端效果

折扣券入口位置不固定，可配在大厅首页 banner、营销广告入口、悬浮图、侧边栏、中部导航、我的页面等多处，进入后即【我的折扣券】；此外充值页选好支付方式与金额后会展示【充值折扣券】区，会员勾选即在本笔充值使用（推荐项默认勾选）。

【我的折扣券】分 未使用 / 已使用 / 已失效。已使用页展示累计折扣与每张【实际充值 X、为您节省 Y】；已失效页保留已过期或后台已删除的券，客户端最长保留 60 天。会员领到折扣券时会弹出获得折扣券弹窗：在线时后台派发，客户端直接弹出；不在线则下次登录后弹出。若同时存在快过期折扣券弹窗，则优先只弹快过期弹窗，始终只保持弹出 1 个。

六、运营建议

场景 建议 提示
拉新促首充 开启【注册后立即自动发放】，配小门槛固定金额券（如充 100 减 9），降低首充门槛。 有效天数设短（如 1～3 天）制造紧迫感。
提客单价 用比例金额 + 折扣上限、或抬高充值门槛（如满 1000 减 10%），引导大额充值。 多档配置，门槛越高优惠越大。
精准触达 用【发放】给指定会员（流失召回、VIP 专享）；按层级/VIP/渠道限定人群。 批量发放走数据上传，单文档≤100 万。
成本与防薅 设置稽核倍数与奖金提现方式限制，避免领券即提；用层级/VIP/同设备同 IP 限制防多号薅。 折扣差额为优惠，需打满稽核才可提现。
效果复盘 看券配置的【未使用/已使用/已过期】与【全部记录】充值金额、赠送金额、使用率，导出报表分析。 使用率低→调门槛/有效期/触达人群。

七、常见问题

Q：折扣券有哪些状态？过期了还能用吗？

A：分 未使用 / 已使用 / 已过期，后台可实时查看。券一旦过期，客户端展示为【已过期】且不可再使用。

Q：折扣券的优惠到账后能直接提现吗？

A：不能直接提。折扣差额是优惠，需打满【稽核倍数】对应的有效投注、且按【奖金提现方式限制】用指定方式提现。

Q：会员领了券为什么客户端看不到？

A：检查折扣券总开关是否开启，以及该会员是否满足公共配置的会员层级、VIP 等级、渠道或代理及使用条件——任一不符都不展示。

Q：改了有效天数，已发出去的券会变吗？

A：未使用的券过期时间会按新天数更新；已失效（已过期）的券不更新。已使用券数据固化。

Q：充值有手续费，会影响满减门槛吗？

A：取决于【领取设置】里的【充值奖励计算是否包含被扣手续费】：包含则按原充值额判断门槛、不包含则按实际到账额判断。例如充 100、手续费扣 5%、到账 95，不包含时按 95 计。
