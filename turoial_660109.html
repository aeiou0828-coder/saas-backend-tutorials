一、功能概述

解决问题 玩家用后台指定的充值方式充值，累计达标即自动升级，并发放对应奖励与积分。
升级口径 只统计后台勾选的指定充值方式的累计金额，达到下一档要求即升级。
奖励构成 晋级奖励 + 日奖励 + 周奖励 + 月奖励 + 赠送积分（按等级倍数）。
积分用途 抽奖（砸金蛋/开宝箱）；积分在获得时即带有效期，到期未用作废。
入口位置 后台：活动 → 金融SVIP；客户端：优惠 → 金融SVIP。

二、配置 SVIP 等级（按币种）

在【活动 → 金融SVIP → 金融SVIP奖励】顶部下拉切换币种，每个币种独立配置一套等级表。

2.1 顶部按钮

按钮 说明
币种切换 切换当前编辑的币种；每个币种独立一套等级表。
应用到所有币种 把当前币种配置一键复制到所有其他币种；常用于站点统一配置。
当前版本 / 详情 查看历史修改记录，仅查看不可回滚。
SVIP 开关 总开关，关闭后客户端隐藏金融SVIP 入口，已生成的待领取奖励也不可再领取。
SVIP 设置 弹窗配置充值方式、各类奖励领取规则、积分、参与限制、SVIP 样式、规则说明等公共项（详见三）。
积分抽奖设置 独立弹窗配置积分抽奖（详见四），可关。
+ 新增等级 列表底部追加空行，可连续点击添加多行后依次填写、点【确认】提交。
批量修改 所有行变可编辑，可逐行改或下载 Excel 整体改后导入（详见 5.1）。

2.2 等级字段

序 字段 说明
1 等级 SVIP0 起，按 SVIP1、SVIP2…顺序排，可新增/删除。
2 币种 当前等级表所属币种，跟顶部下拉一致。
3 晋级再充值 从上一级升到本级需要再充值的金额（升级后从 0 重新累计）。
4 晋级奖金 晋级到本级一次性发放的奖金。
5 本月/本周/本日充值 触发本级月/周/日奖励的最低充值金额（指定充值方式累计）。
6 月/周/日奖励奖金 达标后按周期发放的奖金金额。
7 总奖金上限 日/周/月各自的总奖金上限；空表示不限制。生成奖励时校验是否超上限，超则不生成；领取时也校验。
8 赠送积分倍数 本级每充值 1 送多少积分，等级越高倍数通常越大。

三、SVIP 设置

点【SVIP 设置】打开弹窗，配置充值方式、奖励领取规则、积分、领取限制、样式与规则说明，保存后全局生效。

3.1 充值方式

勾选哪些充值方式，玩家用这些方式充值才计入 SVIP 升级累计，其他方式不计。支持多选，可随时调整，调整后已计入的不变，新充值按新设置统计。

3.2 奖励领取规则（晋级奖金、日/周/月奖励通用）

晋级奖金、日奖励、周奖励、月奖励的领取规则配置项一致，可分别设置。

配置项 说明
领取时间 设置奖励什么时候可以领，如实时、次日、下周、下月等；月奖励选下月时可再指定具体到下月几日几点后可领。
奖励领取过期时间 奖励生成后多少天内未领取就过期，过期后按下方【派发方式】处理。
晋级时是否重复领取 可重复领取（含跨级部分）：一次跨多级时，中间每一档奖励都发；只能领取最高一档：只发达到的最高等级那一档。
派发方式 日/周/月奖励通用。过期自动到账：到期未领自动入账；过期作废：到期未领直接清空。

3.3 积分奖励

配置项 说明
积分奖励开关 关闭后充值不再赠送积分。
赠送积分倍数 按等级表里各等级的倍数赠送，例如 1 倍即每充值 1 送 1 积分。
积分有效期限 SVIP 充值赠送的积分多少天后过期，0 表示当天作废。每笔积分在获得时就按当时配置固定好各自的过期时间。

3.4 领取限制与参与范围

可设置领取终端（PC / Android / iOS / H5 等）、同设备/同 IP/同姓名领取次数、申领条件（如完成绑卡、KYC、首充等）、最近充值次数·金额·天数·打码要求、参与层级、稽核倍数、奖金稽核指定平台、奖金提现方式限制。按站点实际接入情况勾选即可。

3.5 SVIP 样式

下拉选客户端展示样式（如曜石黑金、暖栗棕等），右侧可实时预览效果。

3.6 充值升级说明 / 规则说明

两段面向玩家的文案，均可选系统自带或自定义。充值升级说明展示在客户端头部，规则说明展示在规则说明 tab 内。

四、积分抽奖设置

点【积分抽奖设置】打开弹窗。抽奖与 SVIP 在业务上独立，目前共用入口；可单独关闭，关闭后客户端不展示抽奖。

多币种站点 多品牌站点
序 字段 说明
1 币种 / 品牌组 tab 按币种独立配置；多品牌站点可启用品牌组维度，新增品牌组指定某几个品牌共用一套抽奖配置。
2 是否开启抽奖 关闭后客户端不展示抽奖入口。
3 抽奖方式 砸金蛋 / 开宝箱，二选一，影响客户端动画与样式。
4 每次抽奖消耗积分 每次抽奖扣多少积分。
5 真实成本 期望支出成本，可点【计算真实成本】按当前奖励配置自动算。
6 展示最大金额 客户端宣传的"最高可中"金额。
7 奖励列表 奖励类型（随机奖金/固定奖金/谢谢参与）+ 奖励范围 + 真实中奖概率。点【生成中奖概率】按真实成本与奖励配置反推概率。

五、批量操作与会员等级管理

5.1 批量修改 SVIP 等级表配置

点【批量修改】，所有行变可编辑，顶部按钮变为【下载当前配置】【导入修改】【取消】【确认】。两种用法：

用法 操作
逐行修改 直接在列表里改各等级字段，改完点【确认】提交。
Excel 批量改 点【下载当前配置】拿模板 → Excel 改完 → 点【导入修改】预填到列表 → 检查无误后点【确认】提交。

5.2 修改等级（单个/批量调会员 SVIP 等级）

在【金融SVIP会员列表】顶部点【修改等级】，弹窗操作：
字段 说明
选择方式 单个修改 / 批量修改。
账号类型 会员账号 / 会员 ID 二选一；多条逗号拼接，最多 200 个。
选择 SVIP 等级 下拉选目标等级。
前台/后台备注 各 1000 字以内，前台备注玩家可见，后台仅运营可见。
注意（防薅羊毛）：手动修改等级或导入修正调级后：①晋级累计从 0 重新算；②当级晋级奖励不发；③周期性日/周/月奖励等下个周期才能领。批量操作前请告知玩家或单独配奖励派发。

5.3 补入积分

在【积分抽奖记录】顶部点【补入积分】，给指定会员手动加积分。
字段 说明
添加方式 单次添加 / 批量添加。
账号类型 会员账号 / 会员 ID 二选一；多条逗号拼接，最多 200 个。
补入积分数量 本次补入积分数。
积分有效期限 0-31 天，0 表示今日过期。
前台/后台备注 各 1000 字以内。补入的积分在【积分抽奖记录】里以【系统添加】类型留痕。

六、查看记录

金融SVIP 共 5 个 tab，奖励配置 + 4 个查询页。各查询页作用如下。

tab 作用
金融SVIP会员列表 查看每个会员当前的 SVIP 等级、累计充值、各项奖金与积分；可在这里改等级、导出报表。
金融SVIP充值明细 查看会员符合指定充值方式的充值流水，是升级累计的依据。
等级变更记录 查看会员 SVIP 等级的变化情况，区分系统自动升级和后台手动调整。
积分抽奖记录 查看积分的每一笔变动和抽奖结果。

6.1 积分变动类型（7 类）

类型 含义
充值获得 SVIP 通过指定通道充值获得的积分。
已获得 其他模块（任务、意外惊喜等）奖励的积分；选此类型才出现【优惠来源】下拉。
未使用过期 到积分有效期作废。
抽奖消耗 砸金蛋/开宝箱扣积分。
系统添加 后台手动【补入积分】。

七、客户端展示

入口：优惠 → 金融SVIP（与任务/信用借款/幸运转盘/公积金等并列）。SVIP 样式可换多色。

7.1 主页结构

区域 展示内容
头部 等级图标 + SVIP N + 【去升级】按钮 + 进度条 + "升级还需充值 X" + 升级条件文案（充值升级说明）。
积分卡片 积分数 + 【X 即将过期】红标签 + "每充值 1=N 积分" + 按钮（抽奖、充值等）。
4 个内嵌 tab 金融SVIP奖励 / 规则说明 / 充值记录 / 积分记录。

7.2 奖励列表（金融SVIP奖励 tab）

按等级展示晋级奖金/日/周/月奖金 + 积分倍数；按钮状态：

状态 展示
已领取 奖金后标【已领取】，按钮置灰。
可领取 绿色【领取】按钮可点。
进度未到 显示当前/目标进度条（如 100/1000），按钮置灰。

7.3 积分记录 tab

今日 / 全部时间筛选 + 总计 + 流水。每条流水含变动类型（使用积分/获得积分等）+ 时间 + 来源标签（如来源:每日任务） + 数额 + 抽奖方式与中奖情况（如未中奖、奖金 100、小盲盒 1 次）。

八、运营建议

维度 建议 提示
充值方式选择 勾选成本最低/最稳定/重点要推的充值通道 通道改动后历史不回滚，新充值按新规则；上线前确认通道清单。
领取时间 日奖励选实时领取拉留存；周/月奖励可选下周/下月控成本 实时领取标注【影响留存】，玩家活跃但成本高；选次日/下周/下月会让玩家次日/下周一/下月初再回来。
晋级时重复领 高净值站点选可重复领（含跨级），刺激跳级；中小站点选最高一档控成本 大额玩家一笔充值跨多级时差异显著。
总奖金上限 高等级建议设上限避免极端羊毛；新站点可先空跑数据再卡 空=不限制；调低后已生成奖励不退。
积分有效期 设短（0-7 天）逼玩家及时消耗，提高抽奖触达；设长（30 天+）适合慢热玩家 0=当天作废；与抽奖消耗积分门槛配合，避免攒不出抽奖次数。
抽奖方式 大盘活动选砸金蛋（视觉强、单价高）；常驻入口选开宝箱（节奏快、消耗多） 真实成本要先算再发；展示最大金额会影响玩家点击意愿。
SVIP 样式 高端站点选曜石黑金等深色；大众站点选暖栗棕等亲和色 右侧实时预览客户端效果，先选好风格再发布。

九、常见问题 FAQ

Q：玩家充值了为什么没升级？

A：①检查【SVIP 设置 → 充值方式】是否勾选了玩家用的通道；②【金融SVIP充值明细】里是否有这笔流水；③累计金额是否到达【晋级再充值】要求；④【参与层级】玩家是否在内；⑤【SVIP 开关】是否打开。

Q：调整了 SVIP 设置的充值方式，历史升级会不会变化？

A：不会，已计入的充值记录不回滚，玩家当前等级不变；新充值按新通道判定。

Q：批量修改/导入修正调级后，会员说各种奖励都不能领？

A：这是设计如此，防薅羊毛与运营误操作。手动改等级或导入修正后：①晋级累计从 0 重算；②当级晋级奖励不发；③周期性日/周/月奖励等下个周期才能领。批量操作前请告知玩家或单独配奖励派发。

Q：积分什么时候清零？

A：积分不是统一清零，而是每笔积分在获得时就固定了各自的过期时间，到期各自作废。SVIP 充值获得的积分按 SVIP 设置的积分有效期；其他模块（任务、意外惊喜等）赠送的积分按对应模块自己设置的有效期。过期在【积分抽奖记录】里以【未使用过期】留痕。

Q：抽奖关闭后客户端会怎样？

A：客户端不展示抽奖入口；积分仍可正常累计；已开奖的中奖记录正常入账。

Q：想给某些会员临时加点积分让他们抽奖？

A：用【积分抽奖记录 → 补入积分】，单次或批量、最多 200 个账号、可设 0-31 天有效期；记录在【系统添加】类型里留痕。
