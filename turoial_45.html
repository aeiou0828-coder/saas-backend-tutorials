任务中心 · 操作与运营教程

会员做任务领奖励、攒活跃度，用新人引导、每日每周、三日连续、活跃度宝箱多层任务串起留存与活跃。

目录一、功能概述二、新人福利三、每日 / 每周任务四、三日神秘任务五、活跃度宝箱六、活跃度记录与剩余活跃度七、客户端展示八、运营建议九、常见问题

一、功能概述

任务中心让会员做任务领奖励，同时积累活跃度。由 7 个页签组成，覆盖新会员引导、日常/周期活跃、活跃度经济三大目标。先看整体：

是什么 会员做任务领奖励、同时攒活跃度；活跃度可开活跃度宝箱抽奖或跨模块消耗。
七个页签 新人福利、每日任务、每周任务、三日神秘任务、活跃度宝箱、活跃度记录、剩余活跃度。
奖励到账 任务奖励走【领取与审核】待领取逻辑；领取入口/更多领取限制/稽核倍数等走站点优惠通用配置。
任务活动日期 每日/每周/三日新增任务时可设活动日期（开始-结束时间）。必须在日期内，任务才在客户端展示、才产生奖励、才能领取；不在日期内该任务客户端隐藏不可见。活动日期只控制生效窗口与展示，不改变会员行为数据的统计口径。

二、新人福利

新人福利是新注册会员的一次性引导任务：完成注册、绑定、设置等动作即可领奖，帮助新会员快速上手并留存。任务清单固定不可增删，后台只改奖励与开关。

新人福利列表如下图。
任务清单 固定内置、不可新增删除，会员去站点各页面完成，后台只能改每条奖励与开关。完整清单见下 2.1。
总开关 新人福利开关=总开关，开启后优惠模块或其他入口才展示；客户端只读总开关，总开关开着但任务全关时入口仍展示、点进去为空。
单任务开关 列表每条开关控制该任务显示隐藏；会员层级/币种/品牌不符则不展示对应入口。
按顺序领取 开启后须按后台从上到下排序依次领取（先完成靠后的也要先领完前面的）；关闭则任意顺序领。注意：领取方式选【系统立即自动派发】时不受按顺序领取限制。
提示气泡 开启后客户端对应做任务的页面展示气泡引导，并联动 个人中心-个人资料、安全中心，气泡显示奖励数值。

2.1 新人福利任务清单与完成条件

怎样才能领取奖励：会员完成任务后，奖励进入待领取。按后台【领取方式】——选「手动领取」时，会员需在任务入口点「领取」（开启按顺序领取时须按排序依次领）；选「系统立即自动派发」时，完成即自动到账、不受按顺序领取限制。大额奖励需审核通过才到账。未领取的奖励按站点公共【派发方式】处理——玩家自领·过期作废 / 玩家自领·过期自动派发 / 系统立即自动派发；配合【领取时间】（次日 / 当天实时）与【奖励领取过期天数】统一控制。

2.2 完成任务引导方式设置

在【领取与审核】页面选择页签「全部记录」，点「领取设置」按钮，在设置项「完成任务引导方式」选择引导方式，点「确认」提交后立即生效（全站统一）。两种方式：

跳转到对应页面完成 点「立即完成任务」按钮，跳转对应页面完成任务。如：跳转到个人中心页面完成个人资料填写。
直接弹窗快捷完成 点「立即完成任务」按钮，显示快捷弹窗当场完成任务。如：显示弹窗完成资料填写。

2.3 新人福利设置（公共配置）

新人福利设置是公共配置（多币种/多品牌统一），点新人福利顶部「新人福利设置」按钮进入。
选择币种 / 参与会员 选择生效币种（全选/勾选）与参与会员层级（全选+层级）。
任务时长 长期 / 限时；限时填天数、从注册当天算、可展示倒计时，超期不再展示新人福利。
领取方式 手动领取 / 系统立即自动派发。
领取时间 次日 / 当天实时（当天实时影响留存）。
领取入口 配置奖励在客户端的领取入口（走站点公共配置）。
更多领取限制 防刷/资格限制（KYC、绑卡、同IP/同设备、累计充值/打码等，走站点公共配置）。
稽核倍数 奖金需完成稽核倍数才能提现（走站点公共配置）。
弹框样式 五种样式；多品牌可全品牌统一或按品牌分别设，多币种只选样式。
规则说明 填写展示给会员的活动规则文案。

2.3.1 登录前后弹窗方式（新人福利 / 每日 / 每周 / 三日 通用）

不弹窗 首页不展示该弹窗。
高频弹窗 每次进入首页就弹窗。
每日一次 每日登录后首页弹窗 1 次。
只弹一次 针对会员当前设备/浏览器，总共只弹窗 1 次。
每次登录 每次登录时进入首页弹窗 1 次。
多品牌说明：多品牌站点只有勾选的品牌才算开启对应任务，所有品牌共用当前配置。

2.4 单任务修改弹窗

点任务列表某条的「修改」进入单任务修改弹窗，配置该任务的开关与奖励。绝大多数任务字段一致，个别任务有专属条件（见 2.1 清单备注列）。
品牌名称(ID) 全选 / 勾选（多品牌时只有勾选的品牌算开启，所有品牌共用配置）。
任务条件 只读，展示该任务的完成动作（如「注册账号」「首次下载安装并登录APP」）。
是否开启 控制该任务的显示/隐藏。
提示气泡 开关 + 气泡内容（系统自带 / 自定义）。
奖励类型 固定：各币种直接填奖励金额；随机：各币种设 奖励金额区间 + 期望奖金(0=完全随机) + 展示金额区间。
加倍奖励 开关，开启后选择一个加倍奖励方案。加倍奖励为独立模块统一配置（赠送/充值金额倍数、固定/随机/按充值阶梯倍数、单笔充值领取门槛、倍数 0.01-1000.00）、供各模块调用；主奖励金额为 0 时无法生成加倍奖励。
额外奖励 开关，类型 5 种：活跃度 / 幸运值 / 积分 / 盲盒抽奖次数 / 折扣券；配奖励数量 + 有效天数（活跃度默认每日有效期 1 天，按设置天数计）。
专属条件 个别任务有专属项（新人注册惊喜、首次下载安装并登录APP、添加任意社交账号），详见 2.1 清单备注列。

三、每日 / 每周任务

每日 / 每周任务用可循环的日常目标让会员每天、每周都有事做、有奖领，稳住活跃。两者结构一致，只是结算周期不同。

新增任务弹窗如下图。

3.1 任务重置

每日任务 每日 00:00 重置。
每周任务 周一 00:00 重置。
三日任务 每天从列表随机抽取任务（同币种用户相同）；若有一天任务未完成，则从第 1 天重新开始；连续 3 天完成可领最终奖励并重新开始。

3.2 新增任务与奖励

任务活动日期 设开始-结束时间。必须在日期内任务才展示、才产生奖励、才能领取，不在日期内客户端隐藏不可见。
任务目标 可选一个任务目标新增：累计充值、单笔充值、累计有效投注、单笔有效投注、单笔盈利、单笔亏损、累计盈利、累计亏损、邀请好友（共 9 种）。可新增多个不同任务。
邀请好友口径 任务目标选「邀请好友」时，需选有效判定：完成注册登录 或 完成首充；统计的是周期内新增的下级好友（每日=当天新增，每周=当周新增）。
阶梯奖励 满足的所有阶梯奖励都可领取，每个阶梯奖励只能领 1 次。
额外奖励 活跃度 / 幸运值 / 积分 / 盲盒抽奖 / 折扣券。主奖励可设为 0、仅赠额外奖励（如不给现金只送活跃度 88）。
加倍奖励 需设主奖励（现金）＞1 才生效；点「详情」可查看。加倍奖励为独立模块统一配置、供各模块调用，此处为选择/调用其方案。一次新增的多个阶梯任务共用一个加倍奖励。

四、三日神秘任务

三日神秘任务用连续三天完成的机制拉动会员连续登录：每天随机派任务，连做三天可额外拿最终大奖，中断则重新计天。

三日神秘任务设置如下图。
最终神秘大奖 默认开启，配一个金额区间；会员连续三日完成任务即可额外获得区间内的最终神秘大奖，领取后重新开始。若第1天完成、第2天未完成，则第3天又从第1天重新计。
随机抽取 每天从任务列表随机抽取任务给用户（同币种用户相同）；建议至少配置 5 条任务以确保任务不重复。
其余配置 任务活动日期、参与会员、领取入口、更多领取限制、派发方式、领取时间、稽核倍数等走站点优惠通用配置。
以上每日/每周/三日任务均可设奖金为 0、只赠活跃度；会员可用活跃度开宝箱抽奖。

五、活跃度宝箱

活跃度是会员做任务攒下的通用积分，可用来开活跃度宝箱抽奖。本章讲宝箱配置与活跃度设置。
宝箱开关 开启后前端任务界面才展示宝箱奖励，否则隐藏。
宝箱 目前 4 个、仍在开发（后续支持最多 20 个）；每个宝箱设所需活跃度、奖励类型（固定/随机）。
重复循环开宝箱 允许：活跃度足够可开完一轮后再从第一个继续开（再花对应活跃度）；不允许：一轮只能开一遍，等重置后再开。
宝箱重置 每日重置 / 每周重置。
稽核提现 开宝箱所得奖金需完成稽核倍数才能提现，且只能用指定提现方式。

六、活跃度记录与剩余活跃度

本章讲活跃度的流水记录、剩余查询与后台手动新增。

活跃度记录 记录会员活跃度变动明细；变动类型：已获得、系统添加、活跃度宝箱消耗、过期、商城兑换消耗、兑换失败(已退回)。
剩余活跃度 按会员维度查剩余，一个会员一条，展示总获得、总消耗、总过期、剩余活跃度。
新增活跃度 后台可手动新增：多条添加或批量导入；账号类型 会员账号 / 会员ID（最多 200 个、逗号拼接）；新增活跃度数量 1-999,999,999 正整数；活跃度有效天数 1-31 天（默认每日有效期 1 天，按设置天数计）；填前后台备注。多品牌时按所选品牌新增，一次只能给单个品牌新增。

八、运营建议

按拉新、日常活跃、周期黏性、邀请裂变、活跃度闭环、风控等场景给出配置建议。

场景 建议 提示
拉新留存 新人福利配小额易得任务（绑定/设置类），限时设 3-7 天营造紧迫感，引导新会员完成注册引导链路。 限时从注册当天算，超期不再展示。
日常活跃 每日任务用累计充值/有效投注设低阶梯，让会员每天有事做、有奖领，稳住日活。 阶梯别太高，重在养成习惯。
周期黏性 每周任务放稍高门槛、三日神秘任务用最终大奖拉连续登录；三日任务至少配 5 条防重复。 最终大奖门槛与金额匹配连续 3 日成本。
邀请裂变 邀请好友任务按目标选口径：拉新走完成注册登录，重质量走下级完成首充。 防刷建议用完成首充口径。
活跃度闭环 用额外奖励发活跃度（可主奖励设 0 只送活跃度），再用活跃度宝箱消耗，形成【做任务→攒活跃度→开宝箱】闭环。 允许循环开宝箱可提升消耗，但要算清成本。
加倍提转化 主力任务挂加倍奖励，按赠送/充值倍数或充值阶梯加倍，刺激会员完成更高阶梯。 主奖励现金须＞1、并可设单笔充值门槛才可领。
成本风控 配更多领取限制（KYC/绑卡/同IP同设备）防薅；新人注册惊喜可设注册后X天且X分钟无充值才发，避免薅完就走。 大额走审核，避免刷子套利。
效果监控 看各任务完成率、活跃度发放与消耗、宝箱开启率，据数据调阶梯与奖励。 完成率过低说明门槛偏高。

九、常见问题

Q：新人注册惊喜的奖励条件怎么设？

A：可设「注册 X 天内(1-30) 且 X 分钟内(0-2880，0=注册后立即赠送)没有充值」才发；从注册计时，期间一旦充值即不发，面向观望未充值用户。

Q：任务活动日期外还能领奖吗？

A：不能。必须在任务活动日期内任务才展示、才产生奖励、才能领取，不在日期内该任务客户端隐藏不可见。

Q：未领取的奖励怎么处理？

A：按站点公共派发方式——过期作废 / 过期自动派发 / 系统立即自动派发，配合领取时间与过期天数统一控制。

Q：邀请好友任务怎样算有效？

A：新增时选口径——完成注册登录 或 下级完成首充；统计周期内新增的下级好友。

Q：加倍奖励怎么算？

A：加倍奖励是独立模块统一配置、各模块调用；主奖励现金须＞1，规则可按赠送/充值倍数、固定/随机/充值阶梯，可设单笔充值门槛，倍数 0.01-1000.00。

Q：用户之前已完成动作，任务后开启还能领奖吗？

A：能。完成判定看的是是否已领奖、非真实状态，用户再操作一次即可完成领奖，目前未优化。

Q：允许循环开宝箱是什么意思？

A：会员活跃度足够时，开完一轮所有宝箱后可再从第一个继续开；不允许则一轮只开一遍，等宝箱重置后再开。
